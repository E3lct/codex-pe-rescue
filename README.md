# Codex PE Rescue

[English](README.en.md) · [许可证](LICENSE) · [贡献指南](CONTRIBUTING.md) · [安全说明](SECURITY.md)

旧 Windows 无法启动，只剩 PE 拷出的原始 `.codex` 备份？本工具帮助你从备份中选取本地 Codex 项目和聊天记录，将它们合并到新安装，并为旧项目目录生成新路径映射。项目源代码文件需要单独备份和恢复。

本工具适合重装系统或迁移后找回本地 Codex 历史记录。它会先生成预览，再在客户端关闭后进行有备份的写入。它不要求旧系统提前导出迁移包。

## 安全与适用范围

- 恢复过程在本机处理数据，不会上传恢复数据。首次准备会从 GitHub 下载固定版本的引擎，并从 Python 包索引安装依赖；AI 平台对提示和工具结果的处理由该平台决定。
- 备份、检查结果、工作区和回执可能包含私人聊天或路径。将它们保存在仓库外，不要公开提交。
- 工具不恢复 ChatGPT 云端记录、项目源代码、账号凭据、技能或插件，也不恢复图片和外部附件文件；历史图片可能无法显示。
- **实验性 v0.1.0，Windows 写入适配器。** 它依赖未公开且会变化的本地数据结构，不是 OpenAI 官方导入工具，也不保证兼容所有版本。
- 源和目标数据结构、迁移记录及 `user_version` 必须匹配。工具遇到不兼容情况会停止，不支持旧 JSON 项目登记或数据库版本转换。

## 快速开始：AI 引导

将本仓库链接发给具备本机文件访问和命令执行能力的 AI，并告诉它要恢复旧 Codex 项目或聊天。AI 可从 [仓库 AI 导航](AGENTS.md) 和 [恢复 Skill](skills/codex-pe-rescue/SKILL.md) 找到操作入口；不同 AI 是否自动读取这些文件取决于平台。

AI 会先检查备份并准备预览，只在备份位置、聊天选择或新旧目录对应关系无法判断时询问。你无需手动填写数据库 ID 或 JSON。实际写入前须完全退出 Codex，使用生成的独立启动文件；恢复结束后再核对侧边栏和聊天。

需要可用的 Python 3.11+。普通网页聊天若不能访问本机文件，只能提供操作指导。引导式 AI 操作详见 [恢复流程](skills/codex-pe-rescue/references/assistant-workflow.md)；安装 Skill 是可选的。

## 手动恢复

希望自己运行命令时，按[手动恢复指南](docs/manual-recovery.md)操作。完整操作顺序为：检查备份、选择项目或聊天、设置路径映射、查看预览、关闭客户端后写入、核对结果。
